## The joke

> **Dave booked a 30-minute meeting to read the email he sent at 8:04, then spent 29 minutes apologizing for the email, which had already apologized better in writing.**

Dave books a 30-minute meeting to read the email he sent at 8:04, then spends 29 minutes apologizing for the email — which had already apologized better in writing.

## How it works

`main.py` (stdlib only) writes the joke to `MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), validates it is a single line of 1–200 characters with no tabs and sentence-ending punctuation, and verifies the write by reading it back. The entry file is exactly 163 bytes, with no trailing newline.

```sh
python3 main.py
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
